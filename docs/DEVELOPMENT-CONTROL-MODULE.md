# Development Control Module

**Status: Planned, not started.**

Development Control is planned as a second Atexgrove module for building-plan application intake, document-readiness checks, assistance requests, quotations and consent, and resubmissions. It does not replace the existing Land Verification module.

## Reference form

The reference is the AMAC building plan processing and approval application form. For planning purposes, the module may represent only these printed fields:

| Printed field or notice | Requirement status |
| --- | --- |
| Developer | Unverified; not an official rule. |
| Plot no. | Unverified; not an official rule. |
| Cadastral zone | Unverified; not an official rule. |
| District | Unverified; not an official rule. |
| Street name | Unverified; not an official rule. |
| Dwelling plot/floor | Unverified; not an official rule. |
| Dwelling unit | Unverified; not an official rule. |
| Contact address | Unverified; not an official rule. |
| Developer mobile/email | Unverified; not an official rule. |
| Representative mobile/email | Unverified; not an official rule. |
| Submission type: new, re-submission, revalidation, or other | Unverified; not an official rule. |
| Documents submitted | Unverified; not an official rule. |
| Drawings/reports submitted | Unverified; not an official rule. |
| Submitted by | Unverified; not an official rule. |
| Non-refundable fee notice: ₦10,000 per plot | Unverified; not an official rule. |

These entries record what is printed on the reference form. They must not be presented as current AMAC requirements, fees, or official guidance until the owner confirms them against an authoritative source.

## Planned first slice

The first slice is limited to a checklist represented as data, a readiness status for each checklist item, and a gap report.

Assistance requests, quotations, payments, resubmission comparison, and AI drawing comparison are deferred. Nothing in this brief is implemented yet.
