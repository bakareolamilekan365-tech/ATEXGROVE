# Image assets

Add real, inspectable product or place imagery to the land, property, construction, and professionals folders.

## Landing-page built-environment illustrations

- `atexgrove-built-environment-hero.webp`
- `atexgrove-built-environment-triptych.webp`

Both images are illustrative generated images made with an AI image tool by the Atexgrove project team. The exact tool and generation date were not recorded. The project team supplied and approved them for use in this repository. They must not be presented as photographs of an actual site, property, document or completed Atexgrove project.

The WebP files preserve the original image dimensions while reducing each asset below 300 KB for the free-hosting and mobile-data preview constraints. The former PNG encodings remain recoverable from Git history.
